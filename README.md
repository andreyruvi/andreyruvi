### What I do

- **Architectural BIM modeling:** Revit models built to an agreed LOD, plus families, schedules and view templates
- **Permit drawings:** coordinated residential and commercial sets, taken through plan-check revisions
- **CAD drafting:** AutoCAD drawings from sketches, PDFs, scans or field measurements
- **Scan-to-BIM and as-built models:** point clouds and site data turned into usable models
- **Structural and MEP coordination:** keeping the model and the sheets in step

**Tools:** Revit · AutoCAD · Chief Architect · ArchiCAD · SketchUp · HTML/CSS/JavaScript

### Small tools I've built for design practice

All of these run in the browser, with no install, no build and no upload.

| Project | What it does |
|---|---|
| [massing-study](https://github.com/andreyruvi/massing-study) · [live](https://andreyruvi.github.io/massing-study/) | Early feasibility for one plot: setbacks, buildable envelope, GFA, plot ratio, coverage and overshadowing, shown in axonometric |
| [sheet-check](https://github.com/andreyruvi/sheet-check) · [live](https://andreyruvi.github.io/sheet-check/) | Checks a drawing register before issue: numbering gaps, duplicates, blank title-block fields, stale revisions and paper sizes |
| [site-scatter](https://github.com/andreyruvi/site-scatter) · [live](https://andreyruvi.github.io/site-scatter/) | Paints planting onto a 3D site and exports the model as OBJ, along with a planting schedule |
| [drafting-table](https://github.com/andreyruvi/drafting-table) · [live](https://andreyruvi.github.io/drafting-table/) | Jekyll portfolio theme for building designers, with GFA and plot-ratio fields, a sheet index, and A4/A3 print layouts |
| [gridshift](https://github.com/andreyruvi/gridshift) · [live](https://andreyruvi.github.io/gridshift/) | Accessible sliding-tile puzzle, playable with the keyboard and a screen reader |
